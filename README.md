# 한국수어 영상 작업실

한국수어 영상에서 한국어 글을 만드는 작업을 지원하는 정적 웹앱입니다. 화면은 **Live → 영상 등록 → 내 자료**의 세 탭으로 구성하며, 사전 등록이나 연습을 시작 조건으로 요구하지 않습니다.

현재 **범용 연속 한국수어를 검증된 품질로 자동 번역하는 엔진은 연결되어 있지 않습니다.** 일반 Gemini 영상 이해를 이용한 실험적 초안과 개인 사전의 단어 후보를 제공하고, 원본 영상에 연결된 구간 편집·검토·내보내기를 실제로 수행합니다. 이름이나 문구만으로 한국수어 인식 성능이 개선되었다고 주장하지 않습니다.

## 실행 및 작업 흐름

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

`http://localhost:3000/` 또는 `/#live`는 간결한 Live 진입 화면입니다. **녹화로 시작**을 눌러야 카메라를 요청하고 촬영 작업면을 엽니다. 준비 화면에서 녹화를 시작하고, 마친 영상을 채택한 뒤 글 검토·대화를 이어갑니다. 버튼을 누르기 전, 새로고침, 뒤로·앞으로 이동만으로 카메라를 켜지 않습니다. 연속 수어 자동 통역이나 가짜 자막을 제공하지 않습니다.

`/#video`는 파일 업로드·직접 녹화·직역/한국어 글/문맥 작성, `/#library`는 검색·다시 열기·수정·영상 포함 백업 공간입니다. 이 기존 주소와 `/#settings`, `/#studio`, `/#dictionary`, `/#history` 보조 도구 주소는 유지합니다. 설정은 상단 톱니바퀴에서 엽니다. 배포 환경의 카메라는 HTTPS가 필요합니다.

Live 종료나 탭 이동 시 촬영 트랙과 대기 요청을 정리하되, 현재 영상·미완성 주석·메타데이터·자료 연결을 지우지 않습니다. Live와 영상 등록은 같은 편집 DOM 및 문서를 사용합니다. 작성 중인 영상은 영상 등록에서 이어갈 수 있고, 새 촬영을 열거나 취소하는 것만으로 기존 내용을 교체하지 않습니다. 저장소·스키마·백업 형식 변경이나 데이터 마이그레이션은 없습니다.

연결 및 전송 설정, 촬영 옵션, 백업 설명은 필요한 때 펼칩니다. 실제 외부 전송의 제공자·자료 전체·요금제·비용·개인정보·동의 검토는 그대로 유지합니다. Live는 이 사이트의 작업 화면 이름이며 자체 KSL 모델의 이름이 아닙니다. 로컬 녹화와 문서/저장, UI 훅, 외부 AI 전송 모듈은 분리되어 있지만 현재 연결된 AI는 기존 Google Gemini입니다. 다른 제공자나 신규 서버·모델을 추가하지 않았습니다.

1. 최대 50MB·60초 영상 파일을 선택하거나 **카메라로 영상 녹화**를 누릅니다. 촬영 준비 → 녹화 → 종료 → 원본 방향 미리보기 → **이 영상으로 내용 작성** 순서입니다. 선택·촬영만으로 외부에 전송하지 않습니다.
2. **초안 도구 · 연결 및 전송 설정**에서 보유한 Gemini API 키·실제 프로젝트 요금제·자료 이용 조건을 확인합니다. **전송 내용 확인 → 이번 요청 승인**을 거쳐 대상과 선택한 참고 영상 합계 최대 12MB를 보냅니다. 예시 없이 1회, 예시 참고 1회, 같은 영상 비교 2회 중 선택하며 모두 미검증 초안입니다. API 없이도 영상 재생 위치에 구간을 추가해 직접 한국어 글을 작성할 수 있습니다. 직접 작성은 자동 인식으로 표시하지 않습니다.
3. 각 구간의 시작·끝 시점을 조정하고, 구간 재생으로 영상과 내용을 대조합니다. 모바일에서는 재생 버튼이 원본 영상으로 이동하고 **이 구간 글 수정**으로 편집란에 돌아옵니다. PC에서는 영상과 편집란을 나란히 배치합니다.
4. 글을 수정하고 원본과 대조한 구간에 사용자 검토 표시를 합니다. 글이나 시간을 다시 수정하면 검토 표시가 해제됩니다. 사용자 검토 표시는 모델의 정확도나 번역 품질 인증이 아닙니다.
5. **영상 포함 로컬 저장**을 누르면 영상 원본과 구간별 직역·의역·문맥·검토 상태를 이 브라우저에 함께 보관합니다. **내 자료**에서 다시 열어 수정하고 영상 포함 백업을 내려받을 수 있습니다. 자동 저장은 없으므로 변경 후 다시 저장하세요. TXT·JSON은 글만 내보내며 로컬 자료의 수정 저장을 대신하지 않습니다. API 키는 어느 저장·백업에도 포함하지 않습니다.

잘못된 시간 범위는 오류를 표시하고 저장을 막습니다. 새 분석이 실패하거나 취소되면 이전 편집문을 유지합니다. 새 파일 선택·영상 지우기·재분석에서 저장하지 않은 수정문을 교체할 때 확인하며, 메뉴 이동과 분석 방법 변경은 편집문을 지우지 않습니다. 새로고침·탭 종료 시 미저장 경고는 브라우저 정책에 따라 표시됩니다.

3탭 화면의 회귀 검증은 `node tests/live-workspace.browser.mjs`로 실행합니다. 합성 카메라만 사용하며 초기 요청 0회, 반복 클릭, 권한 거절, 늦은 권한 응답, 탭/이력 이동, 동일 편집기·미저장 문서·기존 자료 보존과 1440/390/320px 화면을 확인합니다.

## 사이트 안에서 녹화하고 자료로 보관하기

자료 녹화는 보조 도구의 단어 동작 등록과 별개입니다. 얼굴·상체·양손과 손을 움직일 공간을 확인하고 촬영하세요. 카메라 선택과 준비 화면의 거울 보기를 지원합니다. **거울 효과는 준비 화면에만 적용하며, 녹화 후 미리보기·편집·저장은 모두 좌우 반전하지 않은 원본 방향**입니다. 마이크 권한은 요청하지 않고 음성 트랙이 없는 영상만 녹화합니다.

녹화 종료 후에는 카메라 트랙을 해제하고 파일을 실제로 다시 읽어 길이·화면을 확인합니다. MP4·WebM 중 브라우저가 지원하는 형식을 사용합니다. 스트리밍 WebM의 길이가 무한대로 표시되는 문제를 피하기 위해 지원하는 컨테이너의 Duration 메타데이터만 보완하고 재검증합니다. 미디어를 재인코딩하거나 외부로 보내지는 않습니다. 지원하지 않는 컨테이너·코덱은 저장 성공으로 표시하지 않습니다.

최대 60초·50MiB이며 종료 지연을 고려해 시간 상한 직전에 자동 종료합니다. 오류·권한 거절·장치 연결 해제·취소·화면 이동·탭 숨김 때는 촬영을 종료하고 트랙을 해제합니다. 아직 응답하지 않은 권한 요청은 브라우저가 계속 표시할 수 있지만, 취소 후 뒤늦게 받은 트랙은 즉시 종료합니다. 미리보기·재촬영·촬영 취소만으로 기존 편집문이나 자료를 교체하지 않습니다.

**이 영상으로 내용 작성**을 누르면 전체 영상 구간을 만들고 직역·자연스러운 한국어 글·문맥을 직접 작성할 수 있습니다. 카메라나 AI를 쓰지 않고 파일을 선택하는 기존 흐름도 유지합니다. `영상 포함 로컬 저장`을 눌러야 영상과 글을 개인 자료실에 보관합니다. 여기서 저장은 현재 브라우저의 IndexedDB이며 클라우드 업로드·기기 간 동기화가 아닙니다. 브라우저 녹화·재생·작성·로컬 저장 자체에는 Gemini API 요금이 없습니다.

## 짧은 영상으로 한 차례씩 대화하기

현재 구현은 한 발화를 녹화하고 확인하는 순차 대화입니다. 상시 카메라 스트리밍 기능이 아닙니다. 영상의 AI 초안이 필요하면 기존 전송 승인 단계를 거치며, 확인한 글을 직접 작성해도 됩니다. 모든 구간의 내용을 검토하고 불확실한 부분을 해소한 뒤 **확인한 글로 답변 받기**를 이용합니다. Gemini 답변 요청에는 사용자가 확인한 한국어 글과 이 탭에서 완료한 이전 대화만 사용합니다. 영상·직역·추가 주석·보관함 자료·여기 ChatGPT 대화나 기억은 자동으로 포함하지 않습니다.

글 전송도 별도의 승인 화면에서 질문·이전 문맥·1회 호출·데이터 이용·비용 조건을 확인합니다. 영상 해석 요청과 한국어 답변 요청은 별도 호출이므로, 둘 다 실행하면 최소 2회입니다. 대화 내용은 현재 탭 메모리에만 보관하며 새로고침 후 유지되는 채팅 이력 저장소는 아닙니다. 새 영상으로 바꾸어도 앞서 확인한 대화는 계속 문맥에 사용되며, 명시적으로 새 대화를 시작하면 초기화합니다. 발화 영상을 자료실에 영구 저장하려면 직접 저장을 선택해야 합니다.

일반 Gemini 모델의 한국수어 해석 품질은 검증되지 않았고, 사용자 검토 표시가 정확도를 보증하지 않습니다. 답변은 확인한 글에 대한 응답입니다. 한국수어가 불명확한 상태에서 이를 확정된 의미로 간주해 자동으로 답변하는 흐름은 제공하지 않습니다. Google의 별도 [Live API](https://ai.google.dev/gemini-api/docs/live)는 향후 검토할 경로이며, 이번 녹화형 기능과 다릅니다. 참조된 ASL 시연은 한국수어 성능이나 이 사이트의 실시간 구현을 입증하지 않습니다. 실시간 경로에는 임시 토큰을 위한 보안 서버, 비디오 표본 빈도와 한국수어 정보 손실, 무료 데이터 처리 조건의 별도 검증이 필요합니다.

## 무료 사용 여부 확인 (2026-10-03)

[현재 모델 문서](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)와 [가격표](https://ai.google.dev/gemini-api/docs/pricing)는 `gemini-3.8-flash` 표준 요청의 무료 티어를 안내하며 [지원 지역](https://ai.google.dev/gemini-api/docs/available-regions)에 대한민국이 포함됩니다. 다만 실제 한도·모델 접근 가능성·결제 연결·청구 상태는 사용자의 Google 프로젝트에서 확인해야 합니다. 앱 코드나 구독 사실만으로 이 사이트의 실제 호출이 추가 지출 없이 실행된다고 판정할 수 없습니다. 이 작업에서 키·청구 계정·잔액을 조회하거나 새 결제·키를 설정하지 않았습니다.

[Google AI 구독 안내](https://ai.google.dev/gemini-api/docs/google-ai-plans)는 Pro·Ultra의 AI Studio 웹 혜택과 외부 API 키 호출의 관리·청구를 구분합니다. Pro에 포함된 [Developer Program Premium](https://developers.google.com/program/plans-and-pricing)의 월 $10 GenAI/Cloud 크레딧은 조건에 따라 Gemini API에 쓸 수 있으나 Google One의 AI 크레딧과는 별개입니다. [결제 안내](https://ai.google.dev/gemini-api/docs/billing/)상 선불 프로젝트는 프로모션 크레딧이 있어도 유료 잔액이 0보다 커야 사용 가능하며 새 선충전의 최소 금액은 $5입니다. 따라서 Pro 구독으로 이 사이트의 추가 지출이 반드시 0원이라고 표시하지 않으며, 이번 작업에서 충전·결제 설정을 요청하거나 실행하지 않았습니다.

무료 서비스에는 개인·민감·기밀 정보를 보내면 안 됩니다. 식별 가능한 얼굴이 포함된 수어 영상을 무료 API로 보내는 용도로 안내하지 않습니다. 대신 로컬 녹화·직접 작성·저장은 이용할 수 있고, 영상에서 직접 확인한 **개인정보 없는 글**만 보내는 경우에도 글과 이전 대화의 분류를 별도로 확인합니다. 성인 개발자의 업무·사업 목적과 EEA·영국·스위스 사용자 대상 유료 서비스 제공 조건 등은 [Google 약관](https://ai.google.dev/gemini-api/terms)을 따릅니다. 실제 사용자 자료로 이 조건이나 KSL 성능을 시험하지 않았습니다.

현재 영상 요청은 `v1beta ...:generateContent`의 inline 영상 경로입니다. 해당 [영상 가이드](https://ai.google.dev/gemini-api/docs/generate-content/video-understanding)에는 `videoMetadata`가 남아 있으나 [API 참조](https://ai.google.dev/api/generate-content#VideoMetadata)는 이를 deprecated로 표시합니다. 검증 없이 대체 형식을 추정해 바꾸지 않았으며, 실제 API 호환성은 후속 확인 항목입니다.

## 개인 영상 자료 · 구현된 1단계

영상에서 한국어 글을 작성하고 다시 확인할 수 있도록 원본과 주석을 연결합니다. `js/personal-library.js`는 기존 사전과 다른 `ksl-personal-library` IndexedDB의 `videos` 저장소를 사용합니다. `js/library-ui.js`는 로컬 저장·검색·선택·복원을 연결하며 네트워크나 API 키에 접근하지 않습니다.

- **함께 저장:** 원본 영상 Blob, 원래 파일명, SHA-256, 자료 ID·수정 번호·저장 시각, 제목·촬영 날짜·촬영 묶음·자료 용도, 구간 시간·원본 AI/단어 후보·직역·자연스러운 한국어 글·상황·지시 대상·의도·불확실성·사용자 검토 상태를 보관합니다. 직역은 표준 수어 글로스로 간주하지 않습니다.
- **저장 확인:** 영상과 주석을 같은 트랜잭션에서 쓰고 완료된 뒤에만 저장 성공으로 표시합니다. 저장 불가·용량 부족 시 메모리 저장을 성공으로 표시하지 않습니다. 같은 자료를 여러 탭에서 고치면 이전 수정 번호의 덮어쓰기를 막습니다. 수정 번호는 최신본의 버전이며 이전 버전을 자동 보관하는 기능은 아닙니다.
- **크기 제한:** 영상당 50MiB·60초, 최대 20자료·영상 합계 200MiB, 최대 100구간입니다. 의역 500자, 각 직역·문맥 필드 1000자이며 한 자료의 전체 주석은 1MiB 미만입니다. 화면의 MB 표기는 1024²바이트 기준입니다. 브라우저의 실제 여유 공간이 먼저 제한될 수 있습니다. 이 제한은 인식에 필요한 자료 개수·영상 품질 기준이 아닙니다.
- **다시 열기:** 새로고침 후 `#library`에서 원본과 주석을 읽습니다. 영상 해시·재생 가능 여부·주석의 영상 길이를 확인합니다. 수정 중인 문서를 교체할 때 확인하고, 취소·뒤로 이동 시 늦게 도착한 열기 결과가 새 작업을 덮어쓰지 않게 합니다. `저장본 연결 해제`는 저장본을 삭제하지 않고 현재 작업을 다음 저장 시 새 자료로 만듭니다.
- **주석 검색과 참고 선택:** 제목·파일명·촬영 정보·원본 후보·직역·의역·문맥의 문자열을 검색합니다. 여러 검색어는 모두 포함되어야 합니다. 영상 의미 검색이나 자동 학습이 아닙니다. `참고 예시` 용도인 자료만 선택할 수 있고 선택은 이번 방문 동안만 유지됩니다. 수정·삭제·확인된 손상 자료의 선택을 해제합니다. 영상 화면에서 선택을 가져온 뒤 전송 목록을 확인하고 요청별로 승인하면 Gemini 참고 자료로 사용합니다. 선택·검색만으로 전송하지 않습니다.

### 영상 포함 백업과 복원

각 자료의 **영상 포함 백업**은 `.kslvideo` 파일 하나에 원본 영상 바이트와 주석을 함께 담습니다. 암호화하지 않으므로 파일 보관·공유 범위는 사용자가 관리해야 합니다. 서버 사본이나 클라우드 동기화는 없으며 같은 기기라도 다른 브라우저·사이트 주소에서는 별도 저장소입니다. 비공개 창 종료·브라우저 데이터 삭제·저장 공간 정리로 사라질 수 있으므로 원본 영상과 백업을 별도로 보관하세요.

**영상 포함 백업 복원**은 파일 형식·버전·크기·구간 범위·SHA-256을 확인하고, 실제 브라우저에서 재생 가능하고 주석과 영상 길이가 맞는지 검사한 뒤 **새 자료**로 저장합니다. 잘못된 파일은 부분 저장하지 않습니다. 기존 자료를 덮어쓰지 않으며 같은 백업을 여러 번 복원하면 별도 사본이 생깁니다. 필요 없는 사본은 백업 후 삭제하세요. 저장된 영상이 없거나 손상이 확인되면 열기·백업·참고 선택을 막고 정상 백업 복원을 안내합니다. 손상된 항목은 삭제할 수 있습니다.

TXT·검토 JSON·기존 단어 사전 JSON에는 원본 영상이 없고 `.kslvideo` 복원 대상이 아닙니다. 아래 연구용 JSON Schema 양식도 별도 제안 형식입니다. 런타임 `.kslvideo` 헤더는 `KSLVID1\n` + big-endian uint32 JSON 길이 + JSON(`format`, `version`, `record`, `video.size/type`) + 영상 바이트입니다. 영상 바이트의 해시는 손상을 확인하며 주석 작성자의 신원·해석 정확성·악의적 변경을 인증하지 않습니다.

아래 2단계는 사용자 선택·요청별 승인 후 예시를 Gemini에 제공하고 비교하는 코드입니다. 모델 가중치 학습은 없습니다. 실제 사용자 자료·키로는 실행하지 않았습니다. 대상의 문맥을 포함한 주석은 모두 전송에서 제외하고, 선택한 참고 예시의 주석만 전송합니다. 세션/날짜/해시 가드가 있어도 잘라낸 영상의 계보나 사람이 정답을 검색어로 넣는 행위까지 자동 판별하지는 않습니다. 공개 저장소에 개인 영상·백업을 올리지 마세요.

## 혼합 Gemini 예시 참조 · 구현된 2단계 (2026-10-03)

원본과 확인한 수정 내용은 기존 로컬 자료에 보관합니다. 필요한 참고 예시만 사용자가 골라 요청마다 Google Gemini API로 전송하며, 자동 업로드·전체 자료 전송·모델 가중치 학습은 하지 않습니다. 일반 영상 모델의 응답을 한국수어 사용자가 검토하는 흐름입니다.

### 요청과 승인

1. 참고 자료의 각 구간에 직역·자연스러운 한국어 글을 작성하고 검토합니다. 불확실성 메모가 있거나 미검토 구간이 있는 자료는 Gemini 예시 제안에서 제외합니다. `참고 예시` 용도로 로컬 저장하세요.
2. 대상 영상의 초안 생성 설정에서 이미 알고 있는 주제로 주석을 검색하거나, 자료 목록에서 골라 둔 예시를 가져옵니다. 최대 2개를 직접 선택합니다. 검색은 문자열 일치이며 영상 의미 이해·자동 정답 검색이 아닙니다. 대상의 정답을 보고 검색어를 만들면 평가가 편향되므로 사용하지 마세요.
비교 대상의 정답 주석도 모든 구간에 직역·한국어 글이 있고 원본과 대조한 검토 표시가 있어야 합니다. 빈 구간·미검토·불확실성이 남은 문서는 저장할 수 있지만 비교 전 확인을 요청합니다. 승인 준비와 실제 요청 직전에 재검사하며, 이 검토 표시는 KSL 정확도 인증이 아닙니다.

3. 실행 방법은 **예시 없이 1회 / 선택 예시 참고 1회 / 같은 영상 비교 2회**입니다. 비교는 하나의 같은 대상 Blob을 같은 모델·8fps·생성 설정으로 순차 요청합니다. 두 번째 요청에는 예시를 추가하고 첫 번째 결과는 넣지 않습니다.
4. 키와 실제 프로젝트의 요금제·이용 조건을 확인합니다. 키 또는 요금제 선택이 바뀌면 확인 체크를 해제합니다. 앱은 키의 실제 과금 상태·잔여 할당량을 조회하지 않으며 무료/유료 표시를 선택한다고 Google 요금제가 바뀌지 않습니다.
5. **전송 내용 확인**은 로컬에서 영상 무결성·참고 자료 버전을 검사하고 대상 파일·참고 제목/수정 번호·각 전체 영상 크기/길이·전송할 주석·호출 수·사용량 계산 예를 보여 줍니다. 구간만 잘라 보내는 기능이 아니므로 영상의 다른 화면·음성도 함께 전송됩니다. 대상의 제목·파일명·직역·의역·문맥·정답은 프롬프트에 넣지 않습니다.
6. 화면에 표시된 내용을 이번 요청에 동의한 뒤 **승인한 내용 전송**을 눌러야 API 요청을 보냅니다. 전송 직전과 비교의 두 번째 요청 전에 자료 버전을 다시 확인합니다. 삭제·수정·영상 누락·조건 변경이 있으면 새 확인을 요구합니다. 승인 토큰은 대상 Blob·참고 Blob·주석·실행 종류에 묶이고 종류별 한 번만 사용할 수 있습니다.

키는 `x-goog-api-key` 헤더에서만 사용하고 저장·백업·URL·로그에 넣지 않습니다. 참고 주석은 JSON 데이터로 분리하며 시스템 지침은 고정된 코드에서만 만듭니다. 영상·주석 안의 지시를 따르지 않도록 요청하고, 응답은 허용된 JSON 필드·시간·길이·초안 상태로 검증합니다. 모델의 지시 무시를 완벽히 보장한다는 주장은 아닙니다. 외부 도구·검색·코드 실행은 연결하지 않습니다.

### 무료 서비스의 실제 제약과 비용

[Google 공식 약관](https://ai.google.dev/gemini-api/terms)에 따르면 무료 서비스의 입력·응답은 제품 개선에 이용될 수 있고 사람이 검토할 수 있으며, 개인·민감·기밀 정보 제출을 제한합니다. 따라서 **얼굴 등 개인 식별 정보가 있거나 판단이 어려운 수어 영상·주석은 이 앱의 무료 경로에서 차단**합니다. 공개 영상이라고 개인정보가 없어지는 것은 아닙니다. 자료 분류는 사용자가 확인하며 자동 비식별화는 하지 않습니다.

활성 결제가 연결된 프로젝트의 유료 서비스는 제품 개선에 입력·응답을 사용하지 않는 조건이 있으나 안전·보안 등의 제한적 보관은 있을 수 있습니다. 연령·개발/업무 목적·제공 지역 조건도 적용됩니다. EEA·영국·스위스의 제공 조건은 약관을 따로 확인해야 합니다. 앱은 기존 키 입력만 지원하고 계정·결제 설정이나 무료에서 유료로의 전환은 수행하지 않습니다. 유료 키를 무료라고 선택해도 실제 과금을 막을 수는 없으므로 실제 프로젝트 상태를 확인해야 합니다.

[현재 모델 목록](https://ai.google.dev/gemini-api/docs/models)과 [모델 설명](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)을 확인해 영상·구조화 출력이 가능한 안정 모델 `gemini-3.8-flash`를 고정했습니다. 2.5 계열은 기존 이용자 중심의 접근 제한이 명시되어 있어 신규 기본 모델로 선택하지 않았습니다. 모델 ID 고정은 영구 이용 가능성이나 KSL 성능 보장이 아닙니다. 실제 프로젝트에서 사용할 수 있는 모델·할당량은 다를 수 있습니다.

[공식 요금표](https://ai.google.dev/gemini-api/docs/pricing)는 3.8 Flash 표준 무료 티어와 유료 토큰 단가를 안내합니다. 2026년 말까지 유료 입력 $0.75/100만·출력 $3.75/100만 토큰(추론 포함), 2027년부터 $1.50/$7.50로 안내되어 있어 확인 화면에 해당 계산 예를 표시합니다. [할당량 문서](https://ai.google.dev/gemini-api/docs/rate-limits)에 따르면 실제 한도는 프로젝트·모델·계정별로 달라 AI Studio에서 확인해야 합니다. 무료 무제한이나 실제 키의 무료 사용 가능성을 주장하지 않습니다.

사용량 계산은 8fps 영상 프레임·음성·주석 글 길이와 고정 지침 여유분을 이용한 **사전 추정**입니다. 요청당 출력 제한은 8,192토큰입니다. 추정은 가격·청구 상한이 아니며 실제 사용량은 응답의 숫자 토큰 필드로 별도 기록합니다. 원본 영상 합계는 12MiB, 각 영상은 60초, 직렬화된 전체 요청은 20,000,000바이트 미만으로 제한합니다. [영상 입력 문서](https://ai.google.dev/gemini-api/docs/video-understanding)에 따라 짧은 영상만 inline으로 보내고 원격 Files API 저장은 사용하지 않습니다. `store:false`는 요청 로깅 옵션이며 약관상의 보관·개선 이용을 전부 없애는 약속이 아닙니다.

429·권한/모델 오류·시간 초과·취소 시 자동 재시도, 다른 모델로 변경, 유료 전환은 하지 않습니다. 다시 실행하려면 새 목록 확인과 승인이 필요합니다. 비교의 첫 요청이 실패하면 다음 요청을 보내지 않습니다. 취소는 이미 Google에 도착한 데이터를 회수하지 못하고 처리된 요청의 요금도 취소하지 못할 수 있습니다.

### 비교·수정·출처 보존

비교 대상은 날짜·촬영 묶음이 있는 `별도 평가용` 저장본이며 저장하지 않은 수정이 없어야 합니다. 참고 자료는 다른 날짜·촬영 묶음이어야 하고 대상과 같은 해시·중복 참고 해시는 거절합니다. 대상의 정답 주석은 로컬 `audit.target.annotations`에만 남깁니다. 같은 원본을 자르거나 다시 인코딩한 파생본과 문장군의 누수까지 자동 검출하는 기능은 아닙니다.

결과 패널은 양쪽 원본 초안을 보여 주고 의미 충실성 우선 결과와 누락·지어냄·불확실성 메모를 사용자가 기록하게 합니다. 두 결과가 완료되어야 비교 선호도를 기록할 수 있고, 중간 실패·취소는 완료된 응답과 중단 상태를 구분합니다. 기존 대상의 정답·편집문은 비교 실행으로 덮어쓰지 않습니다. 사용자가 초안을 편집에 적용한 뒤에도 원본 AI 응답과 실행 당시의 대상 주석은 기록에 따로 남깁니다.

`js/ai-audit.js`는 모델·프롬프트 버전·응답 모델 버전·토큰 사용량·대상 해시·참고 ID/수정 번호/해시/주석·두 원본 응답·사용자 평가를 정규화합니다. `영상 포함 로컬 저장`과 `.kslvideo` 백업은 이를 함께 보존하고, 글 JSON·실행 기록 내보내기도 지원합니다. 저장할 실제 영상과 실행 기록의 대상 해시가 다르면 거절합니다. 최신 문서에 한 실행 기록을 보관하며, 모든 과거 실행을 자동 보관하는 이력 저장소는 아닙니다. 다른 실행과 비교하려면 기록을 내려받거나 저장본 연결을 해제해 새 자료로 보관하세요.

수정한 직역·의역은 사용자가 다시 검토하고 로컬 저장한 뒤 다음 검색·선택의 자료가 됩니다. 확인된 수정이 자동으로 Google 모델의 가중치를 바꾸지 않습니다. 실제 한국수어 의미 충실성·보류 적절성·개인화 효과는 아직 측정하지 않았습니다.

로컬 분석의 단어 후보는 **참고 자료**로만 표시하고 한국어 편집란은 비워 둡니다. 판독 보류 이유는 일부 초안이 있을 때도 화면·저장 파일에 남깁니다. API의 요약문을 별도의 검증된 번역문으로 사용하지 않습니다. 일치도는 저장한 예시와의 유사성이며 확률이나 정확도가 아닙니다.

다음 단계에 필요한 것은 단어 예시를 더 늘리는 것만이 아닙니다.

- 이용·학습·배포 권한을 확인한 **연속 KSL 영상과 대응 한국어 문장**, 시간 정렬, 다양한 수어 사용자·촬영 조건의 데이터가 필요합니다. 얼굴·몸·손의 비수지/수지 신호를 포함해야 합니다.
- 시간에 따른 시각 정보를 처리하는 인코더와 한국어 문장 디코더가 필요합니다. 글로스 기반 접근에서는 영상→글로스 인식과 글로스→한국어 변환을 모두 검증해야 합니다. 글로스→문장 모델만 붙여서는 영상 인식이 해결되지 않습니다.
- 학습에 포함되지 않은 수어 사용자·환경으로 분리한 평가, 한국수어 사용자와의 의미 검토, 미등록·불명확 구간 보류 평가가 필요합니다. 텍스트 점수만으로 의미 보존을 단정할 수 없습니다.
- 허용된 모델 가중치와 전처리 파이프라인을 확보한 뒤 브라우저 또는 승인된 서버의 속도·메모리·개인정보 처리 방식을 검증해야 합니다. 이번 작업에서는 모델 도입·데이터 다운로드·서버 신설을 하지 않았습니다.

## 공개 연구 검토

- [SignOrder](https://github.com/kookmin-sw/capstone-2025-30)는 카페 주문을 중심으로 한 서비스 사례입니다. 한정된 사용 범위의 구조를 참고할 수 있지만, 이 앱의 범용 KSL 영상 번역 성능을 입증하지 않습니다.
- [SSL 연구](https://aclanthology.org/2024.lrec-main.869/)는 재난 안전 KSL 벤치마크와 글로스 토큰화에 따른 변환 결과를 다룹니다. 공개 [연구 저장소](https://github.com/SSL-Sign-Language/Korean-Disaster-Safety-Information-Sign-Language-Translation-Benchmark-Dataset)를 즉시 연결할 수 있는 영상 번역 API로 취급하지 않았습니다.
- [KSL-Guide](https://github.com/ChelseaGH/KSL-Guide)는 문장·단어 영상, 글로스·번역·포즈·타임스탬프 주석을 설명하고 AI Hub 자료로 연결합니다. 학습 자료의 후보이지 이 사이트에 곧바로 연결된 인식 서비스가 아닙니다. 실제 이용 조건과 재배포 권한은 별도 확인이 필요합니다.
- [kslr](https://github.com/cygbbhx/kslr)는 60개 수어 단어의 영상 분류를 설명합니다. 단어 분류와 연속 문장 번역의 범위를 구분했습니다.
- [pose](https://github.com/sign-language-processing/pose)는 좌표 파일 처리 도구이며 언어 번역 모델을 대신하지 않습니다. [LSTM 사례](https://github.com/skidroww/realtime-sign-language-recognition-with-LSTM)의 안정화·유휴 감지 관점과 기존 구현을 대조했지만 코드·가중치·데이터는 복사하지 않았습니다.

이번 조사 범위에서는 권한·KSL 지원 범위·이 앱에서의 실행 및 정확도 검증을 모두 충족하는 즉시 배포 가능한 범용 모델을 확보하지 못했습니다. 그러한 모델이 전혀 존재하지 않는다는 주장은 아닙니다.

## 기존 데이터와 보조 도구

설정에서 개인 사전, 동작 예시 촬영·비교, 기존 비교 기록을 열 수 있습니다. 기본 메뉴와 첫 화면에서는 연습 통계·단어 등록·체험을 주 기능으로 제시하지 않습니다.

- 기존 IndexedDB, localStorage 데이터와 저장 키는 변경하지 않았습니다. 영상 문서를 사전이나 기존 기록에 덮어쓰지 않습니다.
- 단어·동작 예시 백업은 기존 JSON 형식을 유지합니다. 영상은 백업에 포함하지 않으며, 큰 백업은 10MB 이하 여러 파일로 나눕니다.
- 최대 200개 단어·단어당 최근 12개 예시, 구형 데이터 보존·재촬영 안내, 저장소 제한 시 대체 저장 기능을 유지합니다. 기존 Firebase 데이터는 수정하지 않습니다.
- 로컬 손 추적을 실행할 때 jsDelivr에서 MediaPipe 코드·모델을 읽습니다. 등록 예시·손 좌표·영상은 자동으로 원격 저장하지 않습니다. Gemini는 명시적으로 선택하고 전송에 동의했을 때만 해당 영상을 전송합니다.

## UX와 검증

영상과 편집란을 가장 높은 정보 위계에 두고, 분석 설정과 보조 기능은 별도로 배치했습니다. PC는 두 열을 사용하고 큰 화면에서는 영상 패널을 유지하며, 모바일은 한 열과 영상↔구간 편집 이동을 제공합니다. 주요 버튼은 44–48px 이상, 편집 입력은 모바일 확대를 피하도록 16px이며 상태는 글·검토 체크·오류 메시지로 표시합니다. 농인 또는 한국수어 사용자의 선호를 단정하거나 실제 사용성 평가를 완료했다고 주장하지 않습니다.

## 개인화 인식 가능성 검토 · 2026-10-02

목표는 특정 사용자가 표현한 한국수어 영상의 의미와 의도를 보존하는 한국어입니다. 사용자가 제공할 **영상 + 직역 + 의역 + 문맥**은 이를 검증하고 개선하기 위한 자료가 될 수 있습니다. 자료를 저장하는 것만으로 모델이 학습하거나 불완전한 영상에서 숨은 의도를 확실히 알아내는 것은 아닙니다. 아래는 후속 모델 연결을 위한 검토입니다. 경로 A의 영상·주석 로컬 보관과 문자열 검색은 위 1단계로 구현했고, 실제 사용자 영상은 아직 제공되지 않아 실제 KSL 성능 결과는 없습니다.

### 코드 근거

- `js/engine.js`의 `extractHandFeatures`는 두 손의 21개 관절과 상대 위치 등 136차원 특징을 만듭니다. `prepareSignTemplates`와 `matchRecentSequences`는 저장 예시와 시계열 유사성을 비교합니다. 얼굴·시선·몸 자세의 언어적 의미, 담화 지시대상, 한국어 문장 생성 모델은 없습니다. `confidence`는 DTW 거리 기반 유사성이지 의미 이해 확률이 아닙니다.
- `js/video-engine.js`는 영상을 초당 8회 표본 처리하고 같은 matcher를 호출합니다. 손 미검출·모호한 후보 거절과 중복 억제는 있지만 연속 문장 단위 분절·의미 복원은 없습니다. 8fps는 현재 구현 설정이며 한국수어 충분성을 검증한 수치가 아닙니다.
- `js/gemini-video.js`의 요청은 위 2단계에서 명시 승인한 대상·참고 예시로 확장했습니다. 대상 정답은 제외하고 참고 주석만 데이터로 보냅니다. 응답 JSON 검증은 뜻의 정확성 검증이 아니며 모델 ID와 실제 응답 버전을 기록합니다.
- `js/storage.js`의 `saveSample`은 단어별 최근 12개 특징 예시와 해당 단어의 최신 `videoBlob` 하나를 보관합니다. 여러 문장 원본과 직역·의역·문맥을 축적하는 저장소로 재사용하면 자료 연결을 잃을 수 있습니다. 이번 1단계에서는 이 저장소를 건드리지 않고 별도 개인 영상 저장소를 추가했습니다.
- `js/video-document.js`와 `js/app.js`의 `saveVideoDocument`는 원본 초안·편집문·시각·검토 상태를 JSON으로 내보냅니다. 글 JSON 자체에는 원본 영상이 없지만, 새 개인 영상 저장소와 `.kslvideo`에서 원본 해시·직역/의역 분리·수정 번호·영상 포함 복원을 제공합니다. 앞선 합성·모의 테스트는 기능 검사이며 KSL 성능 증거가 아닙니다.

### 차이가 명확한 세 가지 경로

| 경로 | 개인화 방식 | 지금 가능한 범위 | 아직 해결되지 않는 부분 |
| --- | --- | --- | --- |
| A. 로컬 예시 자료·검색·확인 (첫 단계 추천) | 사용자 예시와 주석을 원본에 연결하고 비슷한 후보를 찾아 보여 줍니다. 모델 가중치는 바꾸지 않습니다. | 영상 포함 로컬 입력·검토·주석 문자열 검색·참고 선택을 구현했습니다. 영상 특징 기반 후보 검색이나 모델 학습은 연결하지 않았습니다. | 손 특징만으로 문맥·부정·질문·지시대상을 복원하지 못합니다. 텍스트 태그 검색도 영상 이해를 대신하지 않습니다. |

| C. 영상 모델 미세조정 | 영상·정답 쌍으로 모델 가중치/어댑터를 조정합니다. 이후 매 요청에 모든 예시를 다시 넣는 방식과 다릅니다. | Google Cloud는 영상 supervised tuning을 공식 문서화합니다. 별도 학습 환경·데이터 포맷·서빙 연결이 필요합니다. 현재 앱의 API 키만으로 자동 학습되는 기능은 아닙니다. | 새 클라우드 설정·학습 및 추론 비용·데이터 전송 승인이 필요합니다. KSL을 충분히 이해하는 기반 표현을 확보했는지 먼저 검증해야 하며 과적합과 기존 능력 저하도 평가해야 합니다. |

**추천은 A로 자료 연결과 독립 평가셋을 먼저 준비하고, 별도 전송 동의가 있을 때 B를 예시 없는 기준선과 비교한 뒤 C의 필요성을 판단하는 순서입니다.** A를 완성된 번역기라고 제시하지 않습니다. 외부 전송을 원하지 않는 경우 A를 유지하고, 허용된 로컬 영상 모델을 별도 검토해야 합니다. 현재 환경에 그러한 문장 모델이나 학습 파이프라인이 준비되었다고 주장하지 않습니다.

공식 근거: [Gemini API/AI Studio tuning 안내](https://ai.google.dev/gemini-api/docs/model-tuning)는 현재 해당 인터페이스의 fine-tuning 지원 모델이 없으며 Google Cloud 경로를 안내합니다. [Cloud 영상 tuning](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tuning/video)은 영상 파일·구간과 정답 출력을 담는 데이터 형식을 제공하고, [supervised tuning](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/tuning/supervised-tuning)은 가중치 조정 및 비용을 설명합니다. 따라서 “Gemini는 영상 학습을 전혀 못 한다”와 “현재 웹앱이 이미 개인 학습한다”는 모두 부정확합니다. 지원 모델·지역·권한은 실제 실행 전에 다시 확인해야 합니다.

B는 [공식 영상 입력 문서](https://ai.google.dev/gemini-api/docs/video-understanding)와 [예시 기반 프롬프트 안내](https://ai.google.dev/gemini-api/docs/prompting-strategies)를 조합한 **구현 제안**이며 공식 KSL 개인화 성능 보장이 아닙니다. [One-shot ISLR 연구](https://arxiv.org/html/2502.20171v1)는 고정된 시각 임베딩과 예시 검색으로 새로운 단어를 다루는 방향을 보여 주지만, 연구 범위는 고립 수어 인식입니다. 이 결과를 사용자 KSL 연속 문장·의도 해석 성능으로 이전하지 않았습니다. 앞서 검토한 SSL의 글로스→문장 연구만 연결해도 영상→의미 단계가 생기지는 않습니다. 외부 코드·가중치·데이터는 도입하지 않았습니다.

### 자료 양식: 사용자가 작성할 내용과 자동 메타데이터 분리

초안 파일은 [JSON Schema](schemas/personal-ksl-example.schema.json)와 [입력 예시 양식](examples/personal-ksl-example.template.json)입니다. 기존 사전/검토 문서와 구분되는 별도 형식이며 아직 앱 가져오기 기능에는 연결하지 않았습니다. 예시는 실제 영상이나 학습 정답이 아닌 `is_template: true`인 자리 표시 자료입니다.

| 항목 | 기록 목적 |
| --- | --- |
| 원본 영상 + `asset_id`, SHA-256, 길이, 거울 여부 | 같은 파일·파생 클립을 연결하고 원본을 보존합니다. 브라우저 blob URL이나 임시 파일명만을 영구 식별자로 사용하지 않습니다. 메타데이터는 향후 입력 도구에서 자동 생성할 항목입니다. |
| `signer_id`, 촬영일·세션, 원본 촬영 ID | 실명 대신 구분용 ID를 사용합니다. 같은 날의 연속 촬영·재편집본이 평가셋에 섞이지 않도록 합니다. |
| 구간 시작·끝 | 절/발화와 문맥을 보존해 연결합니다. 단어마다 억지로 잘라 연속 동작의 정보를 버리지 않습니다. 구간 시간은 원본 영상 기준입니다. |
| `literal_ko` 직역 | 사용자가 관찰한 표현 순서·관계·생략을 가능한 한 보존하는 한국어 메모입니다. **표준 gloss, 단어와 일대일 대응하는 전사라고 가정하지 않습니다.** |
| `natural_ko` 의역 | 같은 내용을 자연스러운 한국어로 적습니다. 원문에 없는 원인·감정·목적을 추가하지 않습니다. 동등한 다른 표현도 정답일 수 있습니다. |
| 의도·지시대상·비수지 메모 | 질문/요청/설명 등의 의도, 누구/무엇을 가리키는지, 표현자 기준 공간 위치, 표정·시선·몸 방향에서 실제 확인한 내용을 적습니다. 실명은 꼭 필요하지 않습니다. |
| `available_context` | 실제 분석 전에 이미 주어진 상황이나 영상에서 확인 가능한 문맥만 기록합니다. 대상 영상의 정답을 보고 나서 만든 설명과 구분합니다. |
| 불확실 구간·이유·대안, 검토자·상태 | 모르는 부분은 공란 또는 보류로 남깁니다. 표현자 의도와 제3자 해석이 다르면 차이를 보존합니다. 자동 생성 초안을 검토 없이 정답으로 승격하지 않습니다. |
| 버전·이전 버전·수정자, 문장군·상황군·split | 주석 변경과 실험에 사용한 자료 버전을 재현하고 누수를 방지합니다. |
| 로컬 이용 / 외부 추론 / 외부 학습 / 공개 범위 | 촬영 동의, 외부 추론, 학습, 공개는 별개입니다. 예시 양식은 모두 false이며 체크 값 자체가 실제 동의를 대신하지 않습니다. |

사용자의 우선 입력은 영상·구간·직역·의역이며, 지시대상/문맥이 필요한 경우 보완하고 불확실함을 표시하면 됩니다. 나머지 ID·해시·버전·분할은 도구가 지원해야 합니다. 정확한 수어학적 gloss 표기를 사용자에게 선행 요구하지 않습니다.

**정답 누수 경계:** 대상 영상의 `segments[].meaning` 전체(직역·의역·의도·지시대상)는 평가 정답 영역입니다. 추론 모델, 검색 질의 생성, 프롬프트 선택에 넣지 않습니다. 모델 입력은 질의 영상과 사전에 허용한 `available_context`만 사용합니다. 검색해 선택된 학습/참고 예시의 주석은 참조에 사용할 수 있지만 평가 정답은 사용할 수 없습니다. `available_context` 안에 답을 옮겨 적는 방식도 수동 검토로 차단해야 합니다.

JSON Schema는 구조·타입·날짜·알 수 없는 필드를 검사합니다. `시작 < 끝 ≤ 영상 길이`, 불확실 구간 포함 관계, 실제 파일 해시·중복, 검토·동의의 사실성, 분할 간 누수는 **향후 입력 도구의 별도 의미 검증**이 필요합니다. 지금 양식 검사만으로 데이터가 학습에 적합하다고 판정하지 않습니다.

### 작은 파일럿과 촬영 안내

필요 영상 개수나 정확도는 아직 정할 근거가 없습니다. 먼저 사용자가 실제로 자주 표현하는 한 상황 범위를 정하고, 다음 차이를 구분할 수 있는지를 보는 탐색 파일럿으로 시작합니다. 완벽한 발음처럼 정형화한 수어를 요구하기보다 평소 표현을 보존합니다.

- 손 전체·얼굴·상체·수어 공간이 함께 보이게 촬영하고, 표정·방향·양손 접촉이 잘리지 않도록 합니다. 원본 프레임률과 해상도는 보존하고 흐린 부분·가림·거울 변환을 기록합니다. 특정 fps를 KSL 충분성 기준이라고 보장하지 않습니다.
- 한 자연스러운 발화와 필요한 앞뒤 문맥을 남깁니다. 실제 직역·의역을 먼저 작성한 뒤 모델 출력을 보며 정답을 맞춰 쓰지 않습니다. 얼굴을 가린 자료를 학습 입력으로 쓰면 비수지 정보 손실을 별도로 기록해야 합니다.
- 같은 의미를 평소 다른 방식으로 표현한 예시, 비슷해 보이나 의미가 다른 대조 예시를 포함합니다. 예를 들어 긍정/부정, 질문/진술, 행위자/대상 교환, 시간·수량 차이가 한국어 의미에서 유지되는지 확인합니다. 이는 촬영 주제이지 특정 KSL 동작이나 어순에 대한 처방이 아닙니다.
- 익숙한 표현을 다른 날 새로 촬영하고, 알려진 요소를 새롭게 조합한 문장, 참고 자료에 없는 표현, 손·얼굴 가림이나 쉬는 구간도 평가에 둡니다. 촬영을 실패로 몰아가기보다 어떤 조건에서 보류해야 하는지 확인합니다.
- 사용자 주석이 모호하면 두 해석을 기록하고 확인할 항목을 남깁니다. 독립 KSL 검토자가 참여할 수 있다면 의미 평가의 별도 근거로 활용하되, 참여자의 자료 열람은 별도 동의 범위에서 진행합니다.

### 누수 없는 평가와 중단 기준

1. **분할을 먼저 고정:** 원본 촬영·파생 클립·같은 세션을 한 그룹으로 묶습니다. reference(예시/학습), development(설정·보류 기준), test(최종 비공개 정답)를 분리합니다. 참조 영상의 잘라낸 구간·좌우반전·다른 압축본을 시험 영상으로 쓰지 않습니다. 해시는 바이트 중복만 찾으므로 파생본 계보와 육안 검토도 필요합니다.
2. **평가 축을 분리:** 같은 표현의 다른 날 촬영은 사용자 표현의 반복 일반화, 새 문장군은 조합·문맥 일반화, 미등록 표현은 보류 능력으로 각각 보고합니다. 새 문장군 시험에서는 같은 문장·의역 쌍을 reference에서 제외합니다. 특정 사용자 개인화이므로 다른 사람까지의 성능으로 일반화하지 않습니다.
3. **비교 조건 고정:** (외부 승인 전에는 실행하지 않음) 예시 없는 모델, 동일 모델+참고 예시, 가능하면 나중의 미세조정 모델을 같은 시험 자료·허용 문맥·출력 형식으로 비교합니다. 검색 인덱스는 reference만 포함합니다. 모델 버전·프롬프트·샘플링·선택 예시 ID·보류 기준을 기록하고 시험 결과를 보고 기준을 조정하지 않습니다.
4. **의미를 따로 평가:** 행위자/대상, 행위, 긍정·부정, 시간·수량, 질문·요청 의도가 보존되는지 항목별 판정합니다. 의미에 맞는 자연스러운 다른 한국어 표현도 허용합니다. 잘못된 지시대상·부정 반전은 중대한 오류로 따로 기록합니다.
5. **누락·지어냄·보류를 함께 보고:** 필요한 의미의 누락, 영상/허용 문맥에 없는 의미 추가, 불확실 구간을 확정한 경우를 분리합니다. 답한 구간의 의미 충실성만이 아니라 전체 중 답한 비율과 보류율도 보고해 전부 보류하는 시스템이 좋아 보이지 않도록 합니다. 소규모에서는 실제 건수·분모·실패 사례를 함께 제시하며 높은 정확도를 단정하지 않습니다.
6. **제품 판단:** 예시를 붙인 조건이 다른 촬영일·새 문장에서도 개선되는지, 특정 예시의 답만 복사하는지 판단합니다. 애매한 구간에서 그럴듯한 문장을 늘리거나 중대한 오류가 증가하면 자동 확정을 확장하지 않고 자료/모델 선택을 재검토합니다. 통과 임계값은 파일럿 목적과 허용 오류를 합의한 뒤 정합니다.

출력 흐름은 **구간 재생 → 영상에서 확인한 내용 → 가능한 해석(근거가 있을 때만) → 확인 질문 또는 보류**를 권합니다. 예컨대 “지시대상이 확인되지 않은 구간”으로 남기고 사용자가 대상을 지정하게 합니다. 확인되지 않은 속마음이나 영상 밖 사실을 자연스러운 문장으로 채우지 않습니다. 이 대안·질문 생성은 아직 제품에 구현하지 않았으며, 기존 검토 UI의 다음 확장 제안입니다.

### 지금 준비한 것 / 실제 검증에 필요한 것

기존 UI와 개인 사전을 보존하면서 위 1단계의 로컬 자료 저장·주석·검색·참고 선택·영상 포함 백업/복원을 구현했습니다. 선택 예시를 포함한 Gemini 요청 코드는 위 2단계에 추가했습니다. 실제 사용자 자료의 외부 실행·KSL 성능 검증·모델 가중치 학습은 수행하지 않았습니다. 연구용 JSON 양식의 검토자·권한·계보·허용 문맥 전체를 현재 간단한 입력 UI가 수집하는 것은 아닙니다.

실제 성능 검증에는 (a) 사용자가 선택한 실제 원본 영상과 구간별 직역·의역, (b) 같은 의미의 다른 촬영일 자료와 새 문장·미등록 표현의 평가 자료, (c) 첫 파일럿의 사용 상황 및 불확실할 때 확인 질문을 허용할 범위가 필요합니다. 로컬 열람·특징 추출에 사용할 범위를 먼저 정하고, 외부 모델 비교 시에는 질의 및 참고 영상·주석의 전송 대상과 비용에 대한 **별도 승인**이 필요합니다. 키는 보고서나 자료 파일에 넣지 않습니다. 사용자 자료는 이 공개 GitHub 저장소에 커밋하지 않습니다.

양식 검증은 Python `jsonschema`로 스키마와 자리 표시 예시를 확인하고 음수 시간, 잘못된 해시/날짜, 누락된 직역, 예상 밖 키 및 허용하지 않은 문맥 출처 거절을 확인했습니다. 이는 구조 검사뿐이며 영상·KSL 의미 평가는 미실행입니다. 실제 영상 전송·새 키 설정·유료 학습·대형 모델 다운로드는 모두 미실행입니다.
