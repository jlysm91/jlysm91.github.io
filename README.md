# 손끝 · 수어 스튜디오

카메라로 개인 수어 동작을 등록하고, 저장한 예시와 손동작을 비교해 연습하는 정적 웹앱입니다. 한국어 화면과 PC·모바일 레이아웃을 제공합니다.

## 실행

빌드나 패키지 설치가 필요하지 않습니다.

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

`http://localhost:3000`에서 접속하세요. 파일을 직접 여는 방식 대신 HTTP 서버를 사용해야 ES 모듈이 작동합니다. 실제 배포에서는 HTTPS가 필요하며 GitHub Pages에서 그대로 실행할 수 있습니다.

## 사용

1. 카메라를 시작하고 권한을 허용합니다.
2. **새 수어 등록**에서 단어와 촬영 시간을 선택합니다. 3초의 준비 시간 뒤 촬영합니다.
3. 같은 단어를 반복 등록해 다양한 예시를 추가할 수 있습니다. 단어당 최근 12개 샘플을 보관합니다.
4. **실시간 인식 → 인식 시작**으로 등록한 동작을 연습합니다. 같은 단어를 다시 인식하려면 잠시 손을 내렸다가 보여 주세요.
5. 수어 사전에서 최근 영상을 재생하거나 추가 학습·삭제할 수 있습니다. 설정에서 거울 화면, 관절 표시, 카메라 방향, 인식 기준을 조절합니다.

**먼저 체험하기**는 카메라 없이 화면 흐름을 살펴보는 예시입니다. 실제 수어 영상이나 인식 결과가 아니며, 학습 데이터·연습 통계에 포함되지 않습니다.

## 영상에서 글로

**나의 사전으로 분석**은 최대 50MB·60초 영상을 브라우저에서 재생하며 시간에 따른 손동작을 추적합니다. 등록한 단어만 찾아 시간 구간과 함께 표시하며, 영상이나 분석 결과를 외부로 전송하지 않습니다. 수어 문법이나 문맥을 한국어 문장으로 번역하는 모델은 아닙니다.

**Google AI 영상 읽기**는 Gemini의 일반 영상 이해 API로 한국 수어 해석을 시도하는 실험 기능입니다. 최대 12MB·60초 영상을 지원하며, 개인 Google AI API 키와 영상 전송 동의가 필요합니다. 키는 현재 화면에서만 사용하고 브라우저 저장소에 보관하지 않습니다. 이 모드에서 선택한 영상은 Google로 전송되며 Google의 이용 조건과 API 요금이 적용될 수 있습니다.

모든 AI 결과를 **검토가 필요한 초안**으로 표시합니다. 음성·자막에서 답을 만들지 않고 영상의 한국 수어만 해석하며 불분명하면 판독 불가를 반환하도록 요청합니다. 이 프롬프트가 오해석이나 환각을 완전히 방지하는 것은 아닙니다. 결과를 한국수어 사용자에게 확인해야 합니다.

SignGemma 또는 범용 KSL 전용 번역 모델을 연결했다고 주장하지 않습니다. 공개 한국 수어 연구에는 일부 단어 체크포인트가 있지만 이번 조사에서 바로 배포 가능한 범용 KSL 문장 번역 모델의 지원과 성능을 확인하지 못했습니다. Gemini의 영상 입력 형식은 [Google 공식 예제](https://github.com/google-gemini/cookbook/blob/main/quickstarts/Video_understanding.ipynb)와 [공식 JS SDK](https://github.com/googleapis/js-genai)를 근거로 구현했습니다.

## 데이터

- IndexedDB에 단어, 손동작 특징, 최근 영상을 저장합니다. 제한된 환경에서는 localStorage 또는 임시 메모리 저장으로 전환하고 안내합니다.
- JSON 백업과 가져오기는 **단어와 동작 특징**을 보관합니다. 영상은 백업에 포함되지 않습니다. 큰 백업은 복원 가능한 10MB 이하의 여러 파일로 나누어 제공하며, 각 파일을 차례로 가져오면 됩니다.
- 브라우저 데이터 삭제·기기 변경 전에 백업하세요. 최대 200개 단어, 단어당 12개 샘플을 지원합니다.
- 이전 localStorage의 `signLanguageData`는 그대로 보존합니다. 기존 단어는 옮기되 특징 형식이 달라 재촬영이 필요하다고 표시합니다.
- 기존 Firebase 데이터는 수정하거나 삭제하지 않습니다. 이 버전은 촬영 영상을 자동 업로드하지 않고 기기 내 저장을 사용합니다. 기존 Firebase에만 보관된 데이터는 자동으로 가져오지 않습니다. 영상 분석에서 Google AI 모드를 선택하고 전송에 동의한 경우에만 선택한 파일을 Google로 보냅니다.

## 인식 방식과 한계

MediaPipe Hands로 최대 두 손의 관절을 추적하고, 크기·위치를 정규화한 특징과 제한된 DTW 비교를 사용합니다. 비슷한 단어가 구분되지 않으면 결과를 보류하고, 유지한 자세가 문장에 반복 추가되지 않도록 합니다. 학습 예시가 24개를 넘으면 먼저 유사한 후보를 골라 정밀 비교해 연산량을 제한합니다. 큰 사전에서는 이 후보 선택 때문에 일부 동작을 놓칠 수 있습니다.

일치도는 예시와의 동작 유사성 점수이며 정확도나 검증된 확률이 아닙니다. 표정·몸의 움직임·문법을 해석하지 않는 개인 연습 도구로, 범용 수어 번역기는 아닙니다.

카메라 시작 또는 기기 내 영상 분석 시 jsDelivr에서 MediaPipe 코드·모델을 불러옵니다. 기본 모드에서는 촬영 영상이나 관절 좌표를 원격 서버에 저장하지 않습니다. 화면 글꼴은 사이트에 포함된 Pretendard를 사용하고, 불러오지 못하면 시스템 글꼴로 표시합니다.

## 구성

- `index.html`: 한국어 화면, 접근 가능한 대화상자와 탐색
- `css/styles.css`: 반응형 스튜디오 디자인
- `js/app.js`: 화면 흐름, 카메라·촬영·사전·연습 기록·설정
- `js/engine.js`: 손 추적, 특징 추출, 동작 비교, 녹화 수명 관리
- `js/video-engine.js`: 업로드한 영상의 기기 내 손동작·단어 인식
- `js/gemini-video.js`: 선택적 Google 영상 이해 API와 초안 결과 검증
- `js/storage.js`: 저장·백업·복원과 입력 검증

## 검증

Chromium에서 PC·모바일 화면, 화면 체험과 실데이터 분리, 설정 유지, JSON 가져오기·내려받기, 카메라 실패 복구, 촬영 취소·저장·재시작을 확인했습니다. MediaPipe 실제 코드·모델 로딩과 추적 루프도 확인했습니다. 가상 카메라와 합성 관절 데이터로 흐름을 검증했으며, 실제 사람의 수어 인식 정확도를 측정한 결과는 아닙니다.

순수 특징 비교와 저장·복원 검증은 Node 22 이상에서 다시 실행할 수 있습니다.

```bash
node tests/engine.test.mjs
node tests/storage.test.mjs
node tests/gemini-video.test.mjs
node tests/video-engine.test.mjs
```

검토용 단일 HTML은 아래 명령으로 만들 수 있습니다. 화면 체험·사전·설정은 파일을 직접 열어 확인할 수 있으며, 실제 카메라는 브라우저 정책에 따라 HTTPS 또는 localhost 접속이 필요할 수 있습니다.

```bash
python3 scripts/build-preview.py
```
